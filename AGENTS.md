# AGENTS.md — SIMONA-BT (Премиальный интернет-бутик и O2O digital-витрина)

## 1. Профиль проекта и парадигма разработки
- **Продукт**: Премиальный интернет-бутик и digital-витрина салонов бытовой техники «СИМОНА» (г. Нижний Новгород, домен `simona-bt.ru`).
- **Модель управления**: **AI-Driven Maintenance (No Human CMS)**.
  - Контент-менеджера и классической админки «для людей» нет.
  - Весь контент, структура, правила, визуальный стиль и логика поддерживаются и развиваются AI-агентами через типизированный код, дизайн-токены, схемы данных и скрипты.
  - Архитектура проекта — строго декларативная, модульная и типизированная на TypeScript.
- **Бизнес-модель**: O2O (Online-to-Offline) + Селективный E-commerce (Категория А) + B2B Lead Generation (дизайнеры/архитекторы).
- **Главная цель**: Конвертация онлайн-трафика в физические визиты в салоны на ул. Белинского, записи на персональный тест-драйв «Активной кухни», подбор техники под дизайн-проекты и заключение комплексных B2B-контрактов.
- **Физические пространства**:
  1. *Флагманский салон «СИМОНА»*: ул. Белинского, 15 (крупная и малая премиум-встройка, бренд-зоны Miele / ASKO / Liebherr / SMEG / VARD, «Активная кухня»).
  2. *Фирменный салон OMOIKIRI & KÖRTING*: ул. Белинского, 11/66 (японские мойки, смесители, измельчители, встраиваемая техника).
- **Зонтичный бренд (Umbrella Bar)**: Фиксированная верхняя строка с бесшовным переключателем: `[ ● Бытовая техника ]` (текущий сайт) и `[ Кухни и мебель ]` (ссылка на `simona-kuhni.ru`).

## 2. Каталог товаров и масштабируемость (~8000 SKU)
Каталог содержит около **8 000 позиций**. Подавляющее большинство доступно под заказ, а в наличии и на экспозиции — отборный премиальный пул.

### Гибридная модель карточек (Hybrid Engine):
1. **Категория А: Малая техника, аксессуары, расходники (Прямой E-commerce)**
   - *Примеры*: Чайники/тостеры SMEG, химия Miele CareCollection, бокалы Riedel, фильтры Omoikiri.
   - *Кнопка*: `[ Добавить в корзину ]` / `[ Оформить онлайн ]`.
   - *Флоу*: Корзина -> Оформление -> Доставка/самовывоз -> Онлайн-оплата через **ЮKassa** (СБП, карты, 54-ФЗ).
2. **Категория Б: Крупная и встраиваемая техника (Lead-Gen / O2O сценарий)**
   - Кнопка «Купить в 1 клик» **запрещена** (сохранение премиального клиентского сервиса).
   - Смарт-кнопки по физическому статусу прибора:
     - `🔥 Подключено на «Активной кухне»` (ул. Белинского, 15):
       - Главная кнопка: `[ Записаться на тест-драйв прибора ]` (выбор даты/времени визита).
       - Вторичная кнопка: `[ Скачать схему встройки (PDF) ]`.
     - `📍 В экспозиции` (Белинского, 15 или 11/66):
       - Главная кнопка: `[ Оценить вживую в салоне ]` (бронь визита с экспертом).
       - Вторичная кнопка: `[ Запросить расчет комплекта ]`.
     - `📦 Под заказ / Доставка со склада` (~7500+ позиций):
       - Главная кнопка: `[ Консультация эксперта по модели ]`.
       - Вторичная кнопка: `[ Запросить спецификацию и сроки ]`.

## 4. MCP Figma Protocol: Design-to-Code Pipeline

При разработке, редизайне или создании новых UI-компонентов AI-агенты **обязаны использовать MCP Figma**:

### 4.1. Доступный инструментарий MCP Figma
- `check_api_key` / `set_api_key`: Проверка готовности сессии и ключа Figma API.
- `get_file` / `get_file_nodes`: Чтение структуры файла, страниц, фреймов, Auto Layout параметров (padding, gap, alignment), геометрии и ограничений (constraints).
- `get_image` / `get_image_fills`: Выгрузка изображений, иконок и графических элементов в форматах SVG / WebP / PNG (с поддержкой 2x/3x Retina).
- `get_team_styles` / `get_file_styles` / `get_style`: Синхронизация палитр, теней и типографических стилей с Tailwind.
- `get_team_components` / `get_file_components` / `get_component`: Исследование структуры мастер-компонентов и вариантов (Variants).

### 4.2. Порядок переноса дизайна из Figma в код:
1. **Анализ узла (Node Inspection)**: Получить JSON узла через `get_file_nodes(file_key, ids)`.
2. **Экстракция токенов**:
   - Spacing & Layout -> Tailwind классы (`gap-4`, `p-6`, `grid-cols-12`).
   - Color Fills -> `bg-simona-surface`, `border-simona-border`, `text-simona-teal`.
   - Typography -> `font-montserrat text-sm tracking-wide font-medium`.
   - Corner Radius -> `rounded-xl`, `rounded-2xl`, `rounded-full`.
3. **Выгрузка ассетов**: Логотипы брендов, векторные знаки и пиктограммы экспортировать в виде чистых React SVG-компонентов или оптимизированных файлов в `public/`.
4. **Pixel-Perfect верификация**: Проверка соответствия размеров, отступов и цветовых контрастов на всех брейкпоинтах (Mobile 390px, Tablet 768px, Desktop 1440px, Ultra-wide 1920px).

## 5. Архитектура и технологический стек
- **Фреймворк**: Next.js 14 (App Router, React 18, Server Components, TypeScript `strict: true`).
- **Стилизация**: Tailwind CSS (расширенная палитра `simona.*`), Lucide Icons, Framer Motion.
- **База данных и ORM**: PostgreSQL / SQLite (`prisma/schema.prisma`, Prisma Client 5.22+).
- **Производительность**:
  - Server-Side Rendering (SSR) + ISR для SEO карточек товаров и брендовых хабов.
  - Оптимизация Next/Image с WebP/AVIF форматами.
  - PageSpeed 90+ Desktop / 80+ Mobile, TTFB < 200 мс.
- **Валидация данных**: Zod-схемы для всех форм, API routes и вебхуков.

## 6. Интеграционный контур

### 6.1. 1С: Управление торговлей 11.5
- Синхронизация номенклатуры (~8000 SKU), категорий, характеристик, цен, остатков по складам и признаков наличия/экспозиции (Белинского 15, Белинского 11/66, Склад).
- Выгрузка оплаченных онлайн-заказов (Категория А) в 1С.
- Формат обмена: CommerceML 2.x / REST API / фоновый синхронизатор `lib/integrations/one_c.ts`.

### 6.2. Asana (Управление лидами)
- Автоматическое создание задач на доске проекта «Лиды с сайта simona-bt.ru» (`lib/integrations/asana.ts`).
- Структура задачи: `[Тип заявки] — Имя клиента — Номер телефона`.
- Поля: Все поля формы + UTM-метки + URL источника + вложенные файлы (PDF/DWG планировки от дизайнеров).

### 6.3. ЮKassa (Эквайринг)
- Онлайн-оплата товаров Категории А (Банковские карты, СБП, Mir Pay) (`lib/integrations/yookassa.ts`).
- Фискализация чеков по 54-ФЗ.
- Webhook-обработчик статусов оплаты (`payment.succeeded`, `payment.canceled`).

### 6.4. Яндекс.Метрика
- Настроенные JavaScript-цели на ключевые O2O-конверсии (запись на тест-драйв, бронь визита в салон, скачивание чертежей встройки, B2B-заявки).
- Поддержка электронной коммерции (eCommerce DataLayer) для заказов Категории А.

### 6.5. Telegram-контур
- Мгновенные уведомления о новых лидах, бронях тест-драйвов и заказах в закрытый рабочий чат менеджеров (`lib/integrations/telegram.ts`).
- **Мессенджер-политика**: WhatsApp **не используется**. Все коммуникации — через Telegram и прямой телефон.

## 7. Умный поиск и Онлайн-чат (In-House решения)

### 7.1. Умный поиск по каталогу (Собственное серверное решение)
- Полнотекстовый поисковый движок на сервере (`/api/search`).
- Мгновенная выдача (1–5 мс), нулевая абонентская плата, отсутствие внешних блокирующих скриптов.
- Поддержка русской морфологии, синонимов брендов (Miele / Миле, Asko / Аско, Liebherr / Либхер), поиск по артикулам и приоритет товаров «На активной кухне» и «В наличии».

### 7.2. Telegram-мост онлайн-чата (Live Chat Widget)
- Легкий встроенный виджет чата на сайте с прямым мостом в Telegram менеджеров салона.
- Клиент пишет на сайте -> Менеджеры мгновенно отвечают из рабочего Telegram-чата -> Клиент видит ответ в реальном времени.

## 9. Стандарты качества кода и инженерии интерфейсов
- **TypeScript**: Режим `strict: true`, полный запрет типа `any`.
- **Компонентная структура**:
  - `components/layout/` — UmbrellaBar, Header, Footer, Navigation.
  - `components/home/` — Блоки главной страницы.
  - `components/catalog/` — Сетка товаров, фильтры, карточки, пагинация.
  - `components/modals/` — Модальные окна (Запись на тест-драйв, Заказ звонка, Быстрый просмотр, Корзина).
  - `components/ui/` — Атомарные UI элементы (Buttons, Inputs, Badges, Dropdowns).
  - `lib/integrations/` — Внешние API коннекторы (1C, Asana, Telegram, YooKassa).
  - `types/` — Строгие интерфейсы товаров, заказов, лидов и дизайн-токенов.
- **Code Health**: Код должен собираться без варнингов (`npm run build`), с валидацией типов и отсутствием неиспользуемых импортов.
