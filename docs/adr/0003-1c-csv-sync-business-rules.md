# Наследование бизнес-правил импорта `1C_import.csv` из `ExchangeOneCImportCsv`

В текущем TypeScript-синхронизаторе (`lib/sync/oneCSyncService.ts`) часть колонок `1C_import.csv` (включая `Остаток товара` в колонке 6, `Уценка`, `Не используется`, `Без цены`, `Опт.цена`, `Цвет` и наследование фото/характеристик для карточек спецпредложений по `system_article`) обрабатывалась упрощенно или игнорировалась. Мы решили полностью перенести проверенную бизнес-логику класса `ExchangeOneCImportCsv` со старого сайта UMI.CMS: использовать колонку 6 (`Остаток товара`) как основной складской остаток (с суммированием `disabledAmount` для отключенных дублей спецпредложений), деактивировать товары при `!priceBase`, `isDisabled`, `isDiscount && !amount`, `isRetired && !amount` или при отсутствии фотографий, а для новых карточек спецпредложений автоматически копировать фотографии, описание и характеристики с базовой карточки товара по совпадению очищенного заводского артикула (`system_article`).
