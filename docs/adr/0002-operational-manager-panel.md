# Выделенная операционная панель менеджера и закрытый дашборд аналитики в парадигме «No Human CMS»

Несмотря на общую архитектурную конституцию проекта «AI-Driven Maintenance (No Human CMS)», ежедневная операционная работа салона (обработка заказов, ручная загрузка фотографий для новых позиций из 1С и контроль окупаемости рекламы) не может выполняться через коммиты кода. Мы приняли решение выделить закрытый паролем операционный контур для сотрудников (`/manager/orders` для ведения статусов заказов, заявок и загрузки фото новинок без изображений, а также `/analytics` для сквозной аналитики Директ $\rightarrow$ Сайт $\rightarrow$ Касса 1С), оставив управление структурой сайта, версткой и промо-кампаниями за AI-агентами.
