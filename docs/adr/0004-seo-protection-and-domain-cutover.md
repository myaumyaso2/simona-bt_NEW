# Бесшовный перенос боевого домена simona-bt.ru и сохранение SEO-позиций (301-редиректы, динамический robots.txt и архивный поддомен)

## Контекст
Сайт сети салонов «СИМОНА» более 15 лет работал на UMI.CMS и накопил высокий авторитет в поисковых системах Яндекс и Google, десятки тысяч проиндексированных страниц категорий, брендов и товаров, а также постоянный входящий трафик по внешним ссылкам. При переключении боевого домена `simona-bt.ru` на Next.js 14 критически важно исключить просадку трафика, случайную деиндексацию из-за тестового `robots.txt` и потерю доступа к архиву UMI.CMS.

## Решение
1. **Канонические 301-редиректы**:
   - Товарные страницы: сохранение и дополнение карты из 13 424 точных соответствий старых URL (`/shop/...`) на канонические `/product/[slug]`.
   - Двухуровневая маршрутизация брендов (Tier-1 vs Tier-2):
     - **Tier-1 (13 якорных флагманов и шоурумных брендов)**: `Miele`, `ASKO`, `SMEG`, `Liebherr`, `Körting`, `OMOIKIRI`, `Falmec`, `VARD`, `Midea`, `Bosch`, `Elica`, `Gorenje`, `Evelux`. Для них сохраняются и развиваются ЧПУ-страницы `/brands/[slug]` с премиальным Quiet Luxury представлением (статус дилера, адрес экспозиции в салоне, активные акции из промо-контура и полнофункциональный каталог товаров с фильтрами и табами наличия). Старые URL `/brendy/[slug]/` переводятся 301-редиректом на `/brands/[slug]`.
     - **Tier-2 (Остальные ~40 рядовых брендов)**: для них отдельные лендинги не создаются; со старых адресов UMI.CMS `/brendy/[slug]/` настраивается сквозной 301-редирект сразу на отфильтрованную витрину `/catalog?brand=[BRAND]`.
   - Категории каталога: сопоставление основных разделов UMI.CMS (`/shop/vstraivaemaya_tehnika/...`) с каноническими `/catalog?category=...`.
   - Служебные разделы: сквозной 301-редирект старых URL акций (`/actions_sales/...`), опта (`/optovyj_otdel`), условий сервиса и гарантии на новые разделы.
2. **Динамический `robots.txt`**:
   - Удаление статической блокировки `Disallow: /` для боевого домена.
   - Разделение директив в `app/robots.ts` по хосту:
     - `new.simona-bt.ru` и `old.simona-bt.ru`: `Disallow: /` (защита от индексации дублей);
     - `simona-bt.ru`: `Allow: /`, закрытие служебных путей (`/manager/`, `/profile/`, `/checkout/`, `/api/`), указание `Sitemap: https://simona-bt.ru/sitemap.xml` и директивы `Host`.
3. **Архивный контур UMI.CMS (`old.simona-bt.ru`)**:
   - Сохранение связки Apache + PHP + MySQL на локальном порту 81 и привязка к техническому поддомену `old.simona-bt.ru` под защитой HTTP Basic Auth для архивных сверок сотрудниками салона.
4. **Переключение домена в Nginx (Zero-Downtime Cutover)**:
   - В Nginx переключение `location /` на локальный порт Next.js (PM2 `simona-prod`) при сохранении прямой скоростной раздачи статических медиа (`/images/cms/`) через Nginx.
   - Наличие мгновенного плана отката (Rollback) через `nginx -s reload`.
