# SIMONA-BT (Премиальный интернет-бутик и digital-витрина салонов бытовой техники)

Официальный сайт и O2O digital-витрина салонов бытовой техники **«СИМОНА»** (г. Нижний Новгород, домен `simona-bt.ru`).

---

## 🌟 О проекте

«СИМОНА» — официальный партнер ведущих мировых брендов премиум-класса: **Miele, ASKO, Liebherr, SMEG, Bertazzoni, Falmec, OMOIKIRI, VARD, Schulthess, Körting**.

### Физические пространства:
1. **Флагманский салон «СИМОНА»**: г. Нижний Новгород, ул. Белинского, 15 (крупная и малая премиум-встройка, бренд-зоны, демонстрационная «Активная кухня»).
2. **Фирменный салон OMOIKIRI & KÖRTING**: г. Нижний Новгород, ул. Белинского, 11/66 (японские мойки, смесители, измельчители, встраиваемая техника).

---

## 🚀 Архитектура и стек технологий

* **Фреймворк**: Next.js 14 (App Router, Server Components, TypeScript).
* **Стилизация & UI**: Tailwind CSS, Lucide Icons, Framer Motion.
* **База данных & ORM**: PostgreSQL / SQLite + Prisma ORM.
* **Полнотекстовый поиск**: Встроенный серверный Fast Search с поддержкой морфологии брендов и O2O-приоритизацией (1–5 мс).
* **AI-Driven парадигма**: Без тяжелых human-CMS. Вся структура и бизнес-логика поддерживаются через типизированный код, схемы данных и скрипты.

---

## 💎 Ключевые возможности

1. **Зонтичная навигация (Umbrella Bar)**: Фиксированный переключатель между `[ ● Бытовая техника ]` (simona-bt.ru) и `[ Кухни и мебель ]` (simona-kuhni.ru).
2. **Гибридная модель каталога (Hybrid Engine)**:
   * **Категория А (Малая техника, химия, аксессуары)**: Прямой E-commerce (корзина, выбор самовывоза/доставки, онлайн-оплата ЮKassa/СБП, 54-ФЗ).
   * **Категория Б (Крупная и встройка, ~8 000 SKU)**: O2O Lead-Gen со смарт-кнопками по физическому статусу:
     * 🔥 *Подключено на «Активной кухне» (Белинского, 15)*: Запись на кулинарный тест-драйв + скачивание PDF-схем встройки.
     * 📍 *В экспозиции салона (Белинского, 15 или 11/66)*: Запись на визит с экспертом + расчет комплекта.
     * 📦 *Под заказ со склада*: Консультация по модели + спецификация и сроки.
3. **Lookbook проектов**: Реализованные интерьеры Нижнего Новгорода с интерактивными точками (Hotspots) на встроенных приборах.
4. **Клуб архитекторов и дизайнеров (B2B)**: Партнерская программа (до 10%), проверка схем встройки за 24 часа, салон как переговорная база, загрузка дизайн-проектов (.pdf, .dwg, .zip).
5. **Интеграционный контур**:
   * **Asana API**: Автоматическое создание задач в проекте «Лиды с сайта simona-bt.ru».
   * **Telegram Bot**: Мгновенные уведомления менеджерам и операторский шлюз онлайн-чата.
   * **ЮKassa**: Эквайринг и чеки.
   * **1С 11.5**: CommerceML протокол обмена номенклатурой, остатками и заказами.

## 🛠️ Установка и запуск

### 1. Клонирование и установка зависимостей:
```bash
git clone https://github.com/MyauMyaso/simona-bt.git
cd simona-bt
npm install
```

### 2. Настройка переменных окружения:
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```

### 3. Инициализация базы данных и сидирование:
```bash
npx prisma db push
npx ts-node prisma/seed.ts
```

### 4. Запуск сервера разработки:
```bash
npm run dev
```
Сайт будет доступен по адресу: [http://localhost:3000](http://localhost:3000)

### 5. Сборка для production:
```bash
npm run build
npm run start
```
